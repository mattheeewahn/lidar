# 🤖 배달로봇 - SLAM 네비게이션 시스템

4WD 배달로봇 제어 시스템. 라즈베리파이(Flask) + 아두이노 메가 + CygLiDAR D1

## 시스템 구성

```
┌─────────────────────────────────────────────────────┐
│  웹 브라우저 (PC/스마트폰)                             │
│  - 카메라 스트리밍                                     │
│  - 수동 조종 (W/A/S/D)                                │
│  - SLAM 지도 확인                                     │
│  - 목적지 클릭 → 자율주행                              │
└──────────────────────┬──────────────────────────────┘
                       │ HTTP (WiFi)
┌──────────────────────▼──────────────────────────────┐
│  라즈베리파이 (Flask 서버)                             │
│  - 카메라 MJPEG 스트리밍                              │
│  - CygLiDAR D1 → SLAM 매핑                           │
│  - A* 경로 탐색                                       │
│  - 경로 추종 → 모터 명령 생성                          │
└──────┬──────────────────────────────┬───────────────┘
       │ UART (USB)                   │ UART (/dev/ttyUSB0)
       │ 9600bps                      │ 3Mbps
┌──────▼──────────┐          ┌────────▼──────────────┐
│  아두이노 메가    │          │  CygLiDAR D1 (2D)     │
│  W/A/S/D/Q 수신  │          │  160포인트, 0~120°     │
│  BTS7960 x4 제어 │          │  최대 8m 측정           │
└──────┬──────────┘          └────────────────────────┘
       │ PWM
┌──────▼──────────┐
│  4WD 모터 x4     │
│  (스키드 스티어링) │
└─────────────────┘
```

## 파일 구조

```
delivery-robot/
├── app.py                  # Flask 메인 서버 (실행 파일)
├── motor_controller.py     # 아두이노 시리얼 통신
├── lidar_driver.py         # CygLiDAR D1 드라이버
├── slam_mapper.py          # SLAM 매핑 (점유 격자 지도)
├── path_planner.py         # A* 경로 탐색 + 경로 추종
├── requirements.txt        # 파이썬 의존성
├── templates/
│   └── index.html          # 웹 UI
└── arduino_mega_motor.ino  # 아두이노 코드 (수정 불필요)
```

## 설치 (라즈베리파이)

```bash
# 의존성 설치
pip install -r requirements.txt

# 시리얼 포트 권한 (재부팅 후 적용)
sudo usermod -a -G dialout $USER
```

## 실행

```bash
python app.py
```

브라우저에서 `http://<라즈베리파이IP>:5000` 접속

## 사용법

### 1. 수동 조종
- W/A/S/D 키 또는 화면 버튼으로 로봇 이동
- Q = 정지

### 2. SLAM 매핑
1. "매핑" 탭 클릭
2. "매핑 시작" 버튼
3. 수동으로 로봇을 이동시키며 주변 환경 스캔 (약 1~2분)
4. 지도가 실시간으로 생성됨
5. "매핑 중지" 또는 시간 만료 시 완료

### 3. 자율주행
1. 매핑 완료 후 "네비게이션" 탭 전환
2. 지도 위에서 원하는 목적지 클릭
3. A* 알고리즘으로 경로 계산
4. 로봇이 자동으로 목적지까지 이동
5. 도착 시 자동 정지

### 비상정지
- 화면 우하단 빨간 버튼 또는 Q 키

## 하드웨어 연결

| 장치 | 연결 포트 | 보드레이트 |
|------|----------|-----------|
| 아두이노 메가 | /dev/ttyACM0 | 9600 |
| CygLiDAR D1 | /dev/ttyUSB0 | 3,000,000 |
| USB 카메라 | /dev/video0 | - |

## 아두이노 명령 프로토콜

라즈베리파이 → 아두이노로 단일 문자 전송:
- `W` : 전진 (Forward)
- `S` : 후진 (Backward)  
- `A` : 좌회전 (Turn Left)
- `D` : 우회전 (Turn Right)
- `Q` : 정지 (Stop)

아두이노 코드는 변경하지 않음 (기존 그대로 사용)
